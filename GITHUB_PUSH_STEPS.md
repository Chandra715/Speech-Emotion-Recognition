# GitHub push steps

## 1) Open terminal in this folder
```bash
cd speech-emotion-recognition-github
```

## 2) Initialize git
```bash
git init
git add .
git commit -m "Initial commit - speech emotion recognition project"
```

## 3) Create a new empty repository on GitHub
Example:
`https://github.com/YOUR_USERNAME/speech-emotion-recognition`

## 4) Connect and push
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/speech-emotion-recognition.git
git push -u origin main
```
